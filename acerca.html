Sobre el proyecto

Gestor de Tareas es una aplicación web para crear, organizar y hacer seguimiento de tareas personales, con persistencia de datos mediante localStorage. Desarrollado como Trabajo Práctico Nº1 de Programación II.

Tecnologías usadas

  • HTML5 semántico
  • CSS3 (Flexbox y Grid)
  • JavaScript (DOM, eventos, localStorage)
